# Node.js Projects

This directory contains small, focused Node.js projects designed for learning and practical use. Each project is self-contained and targets specific development tasks.

## Projects

### 1. [JWT Validator](./jwt-validator/)
- **Purpose**: Validate JSON Web Tokens
- **Skills**: JWT handling, async programming, CLI tools
- **Tech**: jsonwebtoken

### 2. [Password Utils](./password-utils/)
- **Purpose**: Secure password hashing and verification
- **Skills**: Security, bcrypt, async operations
- **Tech**: bcrypt

### 3. [API Key Manager](./api-key-manager/)
- **Purpose**: Generate and manage API keys
- **Skills**: Cryptography, security, key management
- **Tech**: crypto, uuid

### 4. [CSV Tools](./csv-tools/)
- **Purpose**: Process and convert CSV files
- **Skills**: File processing, data transformation
- **Tech**: csv-parser, csv-writer

### 5. [File Validator](./file-validator/)
- **Purpose**: Validate file types and security
- **Skills**: File system operations, security scanning
- **Tech**: file-type

### 6. [URL Shortener](./url-shortener/)
- **Purpose**: Short URLs with analytics
- **Skills**: Web development, REST APIs, analytics
- **Tech**: express, nanoid

### 7. [Request Logger](./request-logger/)
- **Purpose**: Log and analyze HTTP requests
- **Skills**: Middleware, logging, monitoring
- **Tech**: express, morgan

## Getting Started

1. Navigate to any project directory
2. Run `npm init -y` to initialize
3. Install the project-specific dependencies
4. Follow the instructions in each project's `info.md`
5. Run the implementation
6. Test and extend functionality

## Learning Path

1. Start with **JWT Validator** for basic Node.js patterns
2. Move to **Password Utils** for security concepts
3. Try **URL Shortener** for web development
4. Explore **Request Logger** for middleware
5. Tackle **API Key Manager** for cryptography
6. Work with **CSV Tools** for data processing
7. Finish with **File Validator** for file operations

Each project builds on the previous ones, gradually increasing in complexity.
