# Task 3: Company Aggregates

## Objective
Learn how to use aggregate functions like `AVG`, `SUM`, and `COUNT` with `GROUP BY`.

## The Data
Table `employees`: `id`, `name`, `department`, `salary`

## The Challenge
Calculate the **average salary** for each **department**.

## Instructions
1. Open `query.sql` in this folder.
2. Write your SQL query inside it.
3. Run it against the database from the `SQL Tasks` root directory:
   ```bash
   sqlite3 tutorial.db < 03-Company-Aggregates/query.sql
   ```
4. Verify your results.

## Expected Output
Two columns: `department` and the calculated average salary.
