# React Calculator

Build a simple calculator using React.

## Tasks

1. Create state for two input values, the operation (+, -, x, /), and the result.
2. Implement a `calculate` function that performs the selected operation on the two numbers.
3. Handle potential errors like "Please enter numbers" or "Cannot divide by 0".
4. Display the result or error message on the screen.
5. Add a "Reset" button to clear the inputs.
