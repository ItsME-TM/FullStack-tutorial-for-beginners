# React Hooks

In this section, you will learn about two most important React Hooks: `useState` and `useEffect`.

## Tasks

### 1. Counter (hooks_basic_1.html)
- Implement a simple counter using `useState`.
- Use `useEffect` to log the count value to the console whenever it changes.

### 2. User List (hooks_basic_2.html)
- Fetch a list of users from `https://jsonplaceholder.typicode.com/users`.
- Use `useState` to store the users.
- Use `useEffect` with an empty dependency array to fetch the data when the component mounts.
